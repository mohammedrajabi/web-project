HTML: structure your first page

Lesson 1 of 3  /  Structure → Style → Interactivity

What is HTML?

HTML (HyperText Markup Language) gives a web page its structure. Elements describe content such as headings, paragraphs, links, and forms.

Anatomy of an HTML document

Document structure

<!DOCTYPE html>
<html>
  <head>Page information</head>
  <body>Visible content</body>
</html>

Build from the outside in

  1. Declare the HTML document type.
  2. Wrap the document in <html>.
  3. Add a <head> for metadata and the title.
  4. Put visible elements inside <body>.

Common HTML elements

Text & hierarchy

  • <h1>–<h6>  Headings
  • <p>  Paragraphs
  • <ul> and <li>  Lists

Links & media

  • <a>  Navigation links
  • <img>  Images with alt text
  • <figure>  Captioned content

Forms & structure

  • <label> and <input>  Fields
  • <button>  Actions
  • <header>, <main>, <footer>
