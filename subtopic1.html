HTML fundamentals

Lesson 1 of 5

What is HTML?

HTML stands for HyperText Markup Language. It uses elements to describe the content and meaning of a page. A paragraph element usually has an opening tag, content, and a closing tag.

<p>This is my first paragraph.</p>

Lesson 2 of 5

Document structure

Every full page starts with a doctype. The html element contains the head, which holds information for the browser, and the body, which holds the visible content.

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>My site</title>
  </head>
  <body>
    <h1>Welcome!</h1>
  </body>
</html>

Lesson 3 of 5

Headings and paragraphs

Use h1 for the main page heading, h2 for the major sections, and h3 for subsections. Use p for paragraphs. A meaningful hierarchy helps readers navigate the content.

<h1>My travel journal</h1>
<h2>Bahrain</h2>
<p>Today I explored the old market.</p>
Next Lesson

Lesson 4 of 5

Links and images

A link uses href to identify its destination. An image uses src for its file and alt for a text alternative that describes its purpose. Use an empty alt attribute for purely decorative images.

<a href="about.html">About me</a>
<img src="market.jpg" alt="Stalls in the old market">
Next Lesson

Lesson 5 of 5

Lists and forms

Use ul for a list without a required order, and ol when the order matters. A form groups inputs. Connect each label to its input by matching for with the input’s id.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>
<form>
  <label for="name">Name</label>
  <input id="name" name="name" required>
  <button type="submit">Submit</button>
</form>
