Website planning

A starting point for new developers

Our purpose

Teach beginners HTML, CSS, and JavaScript through short lessons, practical examples, and interactive exercises.

Our audience

Beginners learning web development, including students creating their first website. No previous coding experience is needed.

Objectives & approach

  1. Define the seven-page structure and a clear learning journey.
  2. Plan content and navigation with low-fidelity wireframes.
  3. Refine the visual system through high-fidelity mockups.
  4. Build accessible, responsive pages and test the learning interactions.

Design decisions

Designed to keep learning clear

A focused dark theme

Navy backgrounds create a consistent setting for lessons and code. Light text and distinct card surfaces keep content readable and clearly grouped.

Cyan with a purpose

Cyan identifies primary actions, active navigation, and important highlights. Using one accent helps learners recognise what they can do next.

Layouts that adapt

Flexible grids become single columns on smaller screens. Touch-friendly controls, scrollable code, and a collapsible menu keep the site usable across devices.

A beginner-friendly interface

Plain labels, familiar controls, visible feedback, and small learning steps help visitors explore, practise, and check their understanding.
