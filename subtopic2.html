02 / CSS foundations

CSS: style and arrange your page

Lesson 2 of 3  /  Structure → Style → Interactivity

What is CSS?

CSS (Cascading Style Sheets) controls how HTML looks. Use rules to change text, spacing, borders, and page layout while keeping content separate from presentation.

Selectors and properties

01 / Select an element

  • Type selector: p
  • Class selector: .lesson
  • ID selector: #welcome

02 / Set a property

  • font-size: text size
  • margin: outer spacing
  • border: visible outline

03 / Choose a value

  • p { font-size: 18px; }
  • .lesson { padding: 24px; }
  • A declaration is property + value.

Understand the box model

Every element is a box

  • Content holds the text or media.
  • Padding adds space inside the border.
  • Border outlines the element.
  • Margin separates it from nearby elements.

Tip: box-sizing: border-box keeps width calculations predictable.

Code example

styles.css  •  CSS

.lesson {
  padding: 24px;
  border: 1px solid #334155;
  border-radius: 12px;
  color: #F8FAFC;
}

Browser preview

Practice: style your welcome page

Add a class to your HTML. Set the heading size, apply 24px of padding to a content box, and add a 1px border.
