CSS fundamentals

Lesson 1 of 7

What is CSS?

Cascading Style Sheets describe how HTML looks. A CSS rule pairs a selector with declarations. Each declaration assigns a value to a property.

p {
  color: #334155;
}
Next Lesson

Lesson 2 of 7

Selectors

A selector chooses the elements a rule applies to. Use p for all paragraphs, .note for elements with class="note", and #intro for the element with id="intro".

p { line-height: 1.6; }
.note { font-weight: 700; }
#intro { max-width: 60ch; }
Next Lesson

Lesson 3 of 7

Colors and backgrounds

The color property sets foreground text color. Use background-color to paint the surface behind it. Check contrast whenever you pick a pair of colors.

.card {
  color: #f8fafc;
  background-color: #1e293b;
}
Next Lesson

Lesson 4 of 7

Fonts and typography

Set a font family with fallbacks so the browser can choose the next available font. Use font-size for text size and line-height for the distance between lines.

body {
  font-family: Inter, system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}
Next Lesson

Lesson 5 of 7

Margin and padding

Padding adds room inside the border, between the content and the edge. Margin adds room outside the border, between this element and its neighbors.

.card {
  padding: 24px;
  border: 1px solid #64748b;
  margin: 16px 0;
}
Next Lesson

Lesson 6 of 7

Flexbox

Flexbox lays out the direct children of a container along a row or column. Set gap for spacing and let children wrap when they need more room.

.toolbar {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: 12px;
}
Next Lesson

Lesson 7 of 7

Responsive design

Start with a layout that fits a small screen. Use a media query to add columns when enough space is available. Resize a browser window to see the rule take effect.

.cards { display: grid; gap: 1rem; }

@media (min-width: 48rem) {
  .cards { grid-template-columns: repeat(2, 1fr); }
}
