What is JavaScript?

JavaScript is a programming language browsers can run. It lets a page react to events, calculate values, and update what readers see.

console.log('Hello from JavaScript!');

Lesson 2 of 7

Variables

Use let for a variable you plan to reassign. Use const when the variable should keep its initial assignment. Pick names that explain what the value represents.

let count = 0;
count = count + 1;
const step = 1;
Next Lesson

Lesson 3 of 7

Data types

Strings represent text, numbers represent numeric values, and booleans are true or false. Quote text to distinguish it from a variable name.

const name = 'Mohammed';
const score = 5;
const isReady = true;
Next Lesson

Lesson 4 of 7

Functions

A function groups instructions you can run again. Parameters accept input when you call the function. Use return to send back a result.

function greet(name) {
  return 'Hello, ' + name + '!';
}

const message = greet('Mohammed');
Next Lesson

Lesson 5 of 7

Conditions

Use if to make a decision. The browser runs the first block when the condition is true and the else block otherwise.

if (score >= 5) {
  console.log('Level complete');
} else {
  console.log('Keep practicing');
}
Next Lesson

Lesson 6 of 7

Events

An event signals something that happened, such as a button click. addEventListener runs a function each time that event occurs on the selected element.

const button = document.querySelector('button');
button.addEventListener('click', () => {
  console.log('Button clicked');
});
Next Lesson

Lesson 7 of 7

DOM manipulation

The Document Object Model (DOM) represents the page as objects. Find an element with querySelector, then update textContent or change its CSS classes.

const heading = document.querySelector('h1');
heading.textContent = 'Welcome back!';
heading.classList.add('highlight');
