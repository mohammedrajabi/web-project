03 / JavaScript foundations

JavaScript: bring your page to life

Lesson 3 of 3  /  Structure → Style → Interactivity

What is JavaScript?

JavaScript adds behaviour to a web page. Store information, respond to clicks, and update the page without reloading it. Start with a small action and build from there.

Three building blocks

Variables

Store a value so you can use it later. Use const for values that do not need reassignment.

const learner = "Sam";

Functions

Group instructions into a reusable action. Call the function when you need it.

function greet() { ... }

DOM interaction

Select an element, listen for an event, and update what appears on the page.

button.addEventListener("click", ...)

Code example

greeting.js  •  JAVASCRIPT

const button = document.querySelector("#hello");
const greeting = document.querySelector("#greeting");

function greet() { greeting.textContent = "Hello, learner!"; }
button.addEventListener("click", greet);

Select an element  →  Listen for a click  →  Update the DOM
